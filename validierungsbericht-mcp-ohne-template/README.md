# Validierungsbericht MCP

Remote MCP wrapper for the deterministic DOCX renderer from plugin 0.4.0.

## Required master template

Before deployment, place the unchanged binary master template at:

`skills/validierungsbericht/references/Validierungsbericht_Template_Plugin_Dynamisch.docx`

Do not rename or modify it.

## Endpoint

After Vercel deployment:

`https://<deployment-domain>/mcp`
